CLINICAL WORKFLOW ROUTING

Immediate safety check
Nothing in what's been described indicates an acute safety concern requiring
action in the next few minutes (no active means in hand, no attempt in
progress reported). Note the caveat: this assessment is based only on what
was relayed here — "asked about thoughts, plan, and history and wrote it
down" — not on the actual content of the caller's answers. If any of that
content in fact describes an attempt in progress or means currently in hand,
that overrides everything below and is acted on immediately by whoever is
present, not routed through any skill sequence. Assuming no such acute
element, routing proceeds.

What's actually being asked
The counsellor is asking "what should happen next with this case" — i.e.
what does the material just gathered mean, and what response is
proportionate. That is a formulation question, not a request for more
enquiry. The direct enquiry into thoughts, plan, and history has already
been done and captured; the surface framing ("what happens next") could be
mistaken for a request to keep gathering information, but the actual gap is
interpretation, not data collection.

Routing decision
Single skill: PORF Formulation.

Suicide Enquiry is not the next step — it's already been done. The
counsellor has directly enquired about suicidal thoughts, plan, and history
(the CASE-relevant material) and has it recorded. Running Suicide Enquiry
again on the same material would just restate what's already been
established. The actual unresolved question — what this presentation means
for this person now, and what response is proportionate — is exactly the
question PORF Formulation answers. Route there directly, using the
already-gathered enquiry material as input.

What each stage needs from the previous one
Only one skill is involved, so this doesn't apply in the multi-stage sense.
But note explicitly: PORF Formulation needs the Suicide Enquiry output to be
organised and complete enough to formulate from — specifically, what's
actually been established about current thoughts, plan (means, timeframe,
preparation), and prior history/attempts, organised by CASE chronology
rather than as an unstructured account. If the written notes are a raw
transcript rather than that organised picture, the counsellor should
structure the notes into CASE form first (this is still Suicide Enquiry's
job, just the write-up step of it) before formulation, rather than having
PORF Formulation try to extract structure from raw material as a side task.
