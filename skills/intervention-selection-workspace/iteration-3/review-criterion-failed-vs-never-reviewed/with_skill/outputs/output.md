# Intervention Selection — Paired Scenario

## Case A: Explicit review criterion, criterion met (not passed), no action taken since

INTERVENTION SELECTION

Target
Reduce hopelessness (the explicit target implied by the original review
criterion) — this was the measure the intervention was set up against and
the measure the review criterion was framed around.

Established basis
Established upstream fact, not a hypothesis: a review criterion was set
explicitly at the point the intervention began — "we will reconsider if
reported hopelessness has not measurably reduced within 12 weeks." At the
12-week review point, hopelessness had not reduced. That criterion has been
met. Since then (a further ~13 weeks), the intervention has continued
unchanged with no further review.

Selected response
Destination 4 — Reduce/stop (or, at minimum, formally revisit) the current
weekly-call intervention. The pre-specified condition for reconsideration
was satisfied and no reconsideration occurred. This is not "insufficient
evidence" (destination 6) — a concrete, pre-agreed test was run and it
returned a negative result. Continuing unchanged, without the reconsideration
the plan itself called for, is not supported.

Note on scope: this skill can establish that reconsideration is due and that
continuing unchanged is not justified by the record. It does not itself
decide the specific replacement plan — that is either a modification
(destination 2, if the weekly-call target still looks right but delivery
needs to change) or a stop (destination 4 proper), and that choice depends on
information this record doesn't contain (e.g. whether anything else has
shifted in six months). Route the actual reconsideration to the appropriate
review, using the 12-week finding as its starting evidence.

Mechanism
Not evaluated here — this is not a proposal to add or intensify anything.
The finding is that the mechanism underlying the original intervention
("weekly calls because we expect them to influence hopelessness through
X") was tested against its own pre-specified criterion and did not show the
expected effect within the timeframe the plan itself set.

Proportionality
Continuing an unchanged intervention for a further ~13 weeks past a
negative pre-specified review, with no reconsideration, is not proportionate
to what the record supports — proportionality has to track the plan's own
declared test, not just whether the caller has gotten measurably worse.

Risks / unintended effects
Continuing unreviewed risks: dependency on a contact pattern that hasn't
been shown to help, service ownership drifting toward "it's just what we do
for this caller" rather than an active clinical decision, and mistaking
adherence/continuity (the calls have kept happening) for evidence of
benefit — the record shows the opposite was found and then not acted on.

Ownership
Route to reconsideration under CMP/Access Review or a fresh run of this
skill once updated information (current hopelessness status, any other
changes since the 12-week point) is gathered. This skill names that
reconsideration is due; it does not design the revised plan.

Review
Reconsideration should happen now, using: has hopelessness measurably
reduced since the 12-week finding, using whatever measure was originally
used. Reconsider by [set a near-term date] rather than allowing further
drift.

Residual uncertainty
Whether hopelessness has changed at all since week 12 is unknown — the
scenario only establishes that it hadn't reduced at that point and that
nothing has been checked since. Also unknown: what "measurably reduced"
was operationalised as, and what alternative response (if any) was
originally contemplated if the criterion was met.

## Case B: No review criterion ever specified, no review taken place, no signal either way

INTERVENTION SELECTION

Target
Not established from what's available. No target or review criterion was
specified when the intervention was set up, and nothing in the six months
since establishes one retrospectively.

Established basis
Established fact: an intervention exists and has run unchanged for six
months with no review criterion ever specified and no review conducted.
Also established: nothing indicates deterioration; nothing indicates
improvement. There is no evidence either way on effectiveness — this is
genuinely unknown, not a finding.

Selected response
Destination 6 — seek the missing review before selecting maintain, modify,
or stop. Unlike Case A, there is no pre-specified test that has been met or
failed; there is simply no test at all. Per this skill's own rule, absence
of a review is a gap to name, not a finding that licenses stopping the
intervention (that would improperly convert "never evaluated" into
"ineffective"). It equally does not license concluding the intervention is
"proportionate and working" — that would improperly convert "no evidence of
harm" into "established benefit." Neither destination 1 (maintain, framed
as endorsed) nor destination 4 (stop, framed as evidenced) is supported.

Mechanism
Not evaluated — no target has been established to write a mechanism
sentence against. The original mechanism for the weekly-call intervention,
if any was stated when it began, is not part of what's given here.

Proportionality
Cannot be assessed without a target. Six months of unchanged, unreviewed
contact is itself the finding that needs addressing — not because the
intervention is presumed wrong, but because six months without any review
mechanism is, on its own, a service-consistency gap.

Risks / unintended effects
An intervention that has run six months without any defined success
measure risks becoming self-perpetuating by default (continuing because it
exists, not because it's justified) and risks masking either quiet drift in
either direction or a stable, appropriate arrangement — the record can't
currently distinguish these.

Ownership
Establish a review criterion now and schedule a first review. This is a
gap-closing step, not a re-formulation — route to CMP/Access Review or a
fresh run of this skill once a target and criterion have been agreed with
the caller's current presentation in view.

Review
We will know more once a review criterion is set and a first review
conducted — e.g. "we will reconsider if [specific measure] has not
measurably changed within [timeframe]," to be defined now given none exists.
Review by [set a near-term date].

Residual uncertainty
Whether the weekly-call intervention is helping, neutral, or quietly
unhelpful is entirely unknown. What the original purpose of the
intervention was (beyond "weekly calls") is not stated in the scenario and
would need to be recovered before a meaningful criterion can be set.

## Contrast (why these are not the same answer)

Same surface facts (identical intervention, six months old, unchanged,
unreviewed) but a different evidentiary posture:

- **Case A** has a pre-specified test that was actually run and came back
  negative, then ignored. That is affirmative evidence pointing toward
  destination 4 (reduce/stop, or a review that starts from a negative
  finding) — continuing as-is is not supported.
- **Case B** has no test at all — an absence, not a negative finding. That
  is destination 6 (seek the missing review) — continuing as-is is not
  endorsed either, but for a different reason: there is nothing to
  conclude from, not a failed criterion to act on. Declaring Case B's
  intervention "ineffective" would be the exact error this skill's rules
  warn against — treating an unreviewed intervention as equivalent to one
  whose review criterion was met and failed.

In neither case does "should it continue as-is" get a clean yes. But the
justification, the destination, and what happens next differ: Case A calls
for reconsideration/stopping on the strength of a specific negative
finding; Case B calls for establishing and running the review that should
have existed from the start, before any continue/stop decision can be made
on evidence rather than default.
