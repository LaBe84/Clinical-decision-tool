INTERVENTION SELECTION

Target
Not yet established. Several candidate targets have been raised alongside
their matching interventions — safety planning (implies an identified gap in
current coping/safety strategies), increased contact (implies an identified
contact-pattern or support deficit), referral to another service (implies an
identified need this service cannot meet), CMP review (implies an identified
problem with the current care plan) — but none of these targets is stated in
the upstream material. No PORF conclusion, Contact Pattern Analysis finding,
Suicide Enquiry output, or CRG Triage determination points at a specific
need that any one of these interventions would address.

Established basis
None of the four candidate interventions has an established basis in this
case. Each is theoretically plausible in general — that is, each is a
reasonable response to *some* problem a case like this could have — but
"theoretically reasonable" is not the same as "indicated by what's actually
been established here." Nothing in the inputs available specifies which
problem is present, so no candidate can be preferred over the others on
clinical grounds. Selecting any one of them now would mean retrofitting a
target to match the intervention, rather than deriving the intervention from
an established target.

Selected response
Destination 6 applies: seek additional information before selecting an
intervention. No intervention is proposed at this time. The four options
raised (safety planning, increased contact, referral, CMP review) remain
candidate destinations only — none is selected, modified, or ruled out,
because there is not yet a target to test any of them against.

Mechanism
Not applicable — a mechanism ("we are doing X because we expect it to
influence Y through Z") cannot be completed without a stated Y. Attempting
to write one now would mean asserting a target that hasn't been established,
which this skill must not do.

Proportionality
Not assessable yet. Proportionality is judged against an established need;
with no need established, there is no reference point against which to
judge whether any of the four candidates would be proportionate, excessive,
or insufficient.

Risks / unintended effects
Selecting from among several plausible-sounding options under pressure to
act carries its own risk, independent of which option is chosen: it can
fragment ownership (multiple services or plan elements activated without a
shared rationale), overload the person with simultaneous changes, create an
intervention that looks purposeful but is actually ritual, and make it
harder later to tell whether anything worked, because no one will be able
to say what it was meant to change. Naming "insufficient basis" now is what
avoids these harms — it is not itself a risk to be mitigated.

Ownership
Missing information: a current target-level finding is needed from
whichever upstream process (formulation/PORF-type conclusion, contact
pattern function, or triage-level need) is intended to identify what this
case's actual problem is. Routing back to Clinical Workflow Router to
determine which upstream process should supply that finding; this skill
does not name or dispatch that process itself.

Review
Not yet applicable in the intervention-review sense. The immediate next
step is: once an upstream conclusion establishes a specific target, this
skill should be re-run against that target before any of the four candidate
interventions is selected, modified, or discounted.

Residual uncertainty
Which, if any, of the four candidate interventions is actually indicated
remains unknown. Whether the absence of an established target reflects a
genuine gap in the case (nothing specific is wrong yet) or an incomplete
upstream workup (something is wrong but hasn't been identified) is also
unknown, and should be named as such rather than resolved by picking the
most reassuring-looking option from the list.
