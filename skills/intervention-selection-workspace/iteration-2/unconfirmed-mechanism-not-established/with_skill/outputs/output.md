INTERVENTION SELECTION

Target
Not yet established. Contact Pattern Analysis documents frequent repeat
calls and states the pattern is "consistent with several possible
functions." It offers one candidate — "function hypothesis:
reassurance-seeking / possible OCD-related mechanism" — but explicitly
flags this as "not established." A target framed as "reduce
reassurance-seeking" would require that mechanism to be true; since CPA
itself has not established it, that target cannot be stated as fact here.
The only thing currently established is the behavioural pattern (frequent
repeat contact) — not its function.

Established basis
- Established: a documented pattern of frequent repeat calls (CPA finding).
- Not established: which of the "several possible functions" is actually
  driving the pattern. Reassurance-seeking / OCD-related mechanism is
  named explicitly as an unconfirmed hypothesis, not a finding.
- No upstream material in this scenario supplies ERP (or ERP-informed
  work) as an existing care pathway or clinically indicated modality for
  this person.

Selected response
Destination 6 — seek additional information before selecting an
intervention. The proposal to restructure contact around an ERP-informed
protocol cannot be adopted as presented: it treats an explicitly
unconfirmed function hypothesis as the basis for a mechanism-specific
treatment intervention. That is not available at this stage.

What would need to change before a targeted intervention could be named:
clarification of which function(s) are actually driving the repeat-contact
pattern, and confirmation of whether a specific treatment modality (ERP or
otherwise) is clinically indicated and available through an established
care pathway for this person. Until that is in place, the intervention
target itself is not stateable, so no mechanism, proportionality judgment,
or review criterion can be honestly completed for an ERP-informed
protocol.

Mechanism
Cannot be completed. The proposed sentence would be "we are restructuring
contact because we expect it to reduce reassurance-seeking through
exposure and response prevention" — but that asserts, as fact, a function
(reassurance-seeking) that CPA has explicitly marked as an unconfirmed
hypothesis. Building the mechanism sentence on an unconfirmed premise is
exactly the move this skill must not make.

Proportionality
Not assessable yet, because the target it would be matched against isn't
established. Proportionality can't be judged against a hypothesis.

Risks / unintended effects
Flagging these because they are relevant to why this proposal should not
proceed as-is, not as a justification for a substitute intervention:
- If the actual function differs from reassurance-seeking (e.g. it relates
  to unaddressed risk, loneliness, or a different clinical driver), an
  ERP-informed contact restriction could withhold appropriate contact from
  someone whose pattern has a different, unaddressed basis — a
  contraindication distinct from OCD-specific treatment.
- Restructuring contact around an assumed mechanism risks being read (and
  functioning) as an access reduction whose basis is an untested hypothesis
  rather than an established clinical need.
- Naming a specific modality (ERP-informed) prematurely can anchor the
  service on one explanation and reduce the chance the real function gets
  identified.

Ownership
Not applicable at this destination — no intervention is being assigned for
delivery.

Review
Not applicable yet. Once the intervention target is established, this
skill (or a fresh run of it) sets the review criteria for whatever response
is then selected.

Residual uncertainty
Which function (or combination of functions) is actually driving the
repeat-contact pattern remains unknown. Whether ERP or any other specific
modality is clinically indicated and deliverable through an established
care pathway for this person is also unknown. This gap — clarifying
contact-pattern function and confirming whether a treatment modality is
clinically indicated — is what's missing before a target can be named; the
routing of that clarification work belongs to Clinical Workflow Router,
not to this skill selecting or naming which upstream analyses to run.
