# Formulation

This area will hold the authoritative Prevention-Oriented Risk Formulation (PORF) model used by the system.

It should define the formulation domains, interpretation rules, treatment of uncertainty, relationship between status/state/resources/foreseeable change, and the requirement that response follows formulation.

The canonical model must be source-controlled independently from the PORF skill. The skill applies the model; it should not be the sole location in which the model itself exists.
