# PORF reasoning boundaries — canonical draft

**Status:** DRAFT. PORF source/version and source-concordance require verification; this draft does not approve a reference population or local threshold.

PORF is comparative clinical interpretation, not risk-factor counting or a prediction of suicide. It distinguishes enduring status, current state relative to the person's own baseline, usable resources, foreseeable change, and material uncertainty.

- A Risk Status comparison requires a specified valid reference population. If no valid comparator is available, do not create pseudo-precision: report enduring vulnerability directly and state the limitation.
- Risk State is a within-person comparison; without baseline, describe current indicators and uncertainty rather than claiming deterioration.
- A resource must be available, accessible, acceptable, and likely to be used to be treated as usable. Absence of confirmation is not unavailability.
- Foreseeable change is plausible and credibly linked to the formulation, not speculative.
- The response follows the integrated formulation and uncertainty—not a sum of factors, contact volume, denial alone, chronicity, staff anxiety, or incomplete information alone.
- Formulation states the needed clinical response; organisational procedure specifies how it is implemented.
