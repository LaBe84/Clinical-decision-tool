# Escalation and Decision Locus

This area will hold canonical decision logic governing escalation between routine Helpline management, immediate operational/safety decision-making and CRG/shared formulation review.

Initial principles already reflected in the CRG skill:

- Complexity is a property of a case; escalation is a property of the unresolved decision.
- Oversight escalation is not synonymous with risk escalation.
- Contact volume alone does not determine CRG referral.
- CRG should not be used simply to obtain another opinion where the current level can reasonably make the required decision.

Exact thresholds and organisational destinations require policy/governance provenance before being treated as approved canonical rules.
