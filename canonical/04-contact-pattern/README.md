# Contact Pattern and Function

This area will hold canonical principles for interpreting contact patterns.

Initial cross-skill rules already present in the repository include:

- Behaviour is not function.
- Increased contact is not automatically deterioration.
- Reduced contact is not automatically improvement.
- Stable contact does not establish that the current intervention is effective.
- Contact volume alone does not determine clinical response, CRG escalation or access restriction.

The canonical layer should distinguish observable pattern from hypothesised function and require function to be supported by the available formulation/evidence rather than inferred from frequency alone.
