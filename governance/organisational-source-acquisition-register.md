## Acceptance criteria for live-use source control

Before a rule is changed from provisional to operationally approved, the source record must include:

1. title, owner, version/effective date and review date;
2. an identifiable approval route;
3. a secure document location and text that directly supports the rule;
4. relevant scope, exception and documentation requirements;
5. confirmation that the source is current for Lifeline’s operating model.

## Rules while source control is incomplete

- Canonical drafts may state only the recorded high-level boundaries.
- Skills must not invent mandatory thresholds, destinations, procedures or restrictions.
- Regression tests may verify source deferral and documented high-level boundaries, but not unverified operational details.
- A source title or summary is not evidence that every existing skill statement is approved.
