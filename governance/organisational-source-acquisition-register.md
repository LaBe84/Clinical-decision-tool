## Acceptance criteria for a controlled source

Before a rule is changed from provisional to approved, the supplied document must have:

1. a title, owner, version/effective date and review date;
2. an identifiable approval route;
3. text that directly supports the rule—not merely a related service description;
4. any relevant scope, exception and documentation requirements;
5. confirmation that the source is current for Lifeline’s operating model.

## Rules while this register is incomplete

- Canonical drafts may state reasoning discipline and policy precedence only.
- Skills must not invent mandatory thresholds, destinations, procedures or restrictions.
- Regression tests may verify deferral to policy, but not policy conformance.
- The absence of a controlled document is a governance gap, not evidence that an existing skill rule is approved.
