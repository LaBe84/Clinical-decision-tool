## Source-control rule

A named model is not source-controlled merely because the repository contains a skill named after it, or because an external publication is listed above. The skill is an implementation. Source control requires a confirmed adopted version, an accountable owner, any approved local adaptations, and a review date.

## Public-service boundary

Public Belfast Trust material confirms that Lifeline is a 24/7 crisis-support service, but it does **not** establish internal CRG destinations, CMP/access restrictions, emergency workflow, or safeguarding procedure. Those rules remain provisional until controlled organisational documents are linked and approved.
