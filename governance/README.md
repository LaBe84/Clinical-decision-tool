# Governance

This directory records the provenance and status of consequential clinical/service rules.

A governed rule should eventually identify:

- rule/model name;
- status: draft / locally agreed / formally approved / superseded;
- source or authority;
- owner;
- date/version;
- rationale;
- affected skills and decision tools;
- required eval/test coverage;
- superseded version where applicable.

Repository presence does not itself constitute organisational approval.
